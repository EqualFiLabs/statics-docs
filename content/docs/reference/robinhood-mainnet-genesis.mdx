This page records the live STATICS Genesis deployment on Robinhood Chain. It covers the fixed STATICS token, the STATICS/WETH market, Operators, the Genesis vault, vesting, and launch rewards.

It does not include the basket, Statics Dollar, lending, or protocol-pool diamonds. Those contracts are recorded on the [Robinhood testnet deployment](/docs/reference/robinhood-testnet-deployment). Do not use testnet addresses on this network.

The canonical file is [`deployments/robinhood-mainnet-genesis.json`](https://github.com/EqualFiLabs/statics/blob/master/deployments/robinhood-mainnet-genesis.json) in the protocol repository. Availability of the rest of the protocol is on [Rollout](/docs/rollout).
