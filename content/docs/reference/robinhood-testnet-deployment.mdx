This page records two deliberately distinct Robinhood Chain Testnet snapshots.
The older public integration-beta release remains the stable address/ABI
reference for existing integrations. A newer September 2026 full-stack
rehearsal is recorded separately and is not asserted to be live or healthy here.
`deployment.md` in the source repository is canonical for both manifests.

For what users can do today versus later creation access, see
[Rollout](/docs/rollout). First actions:
[Testnet onboarding](/docs/start/testnet-onboarding).

## September 2026 full-stack rehearsal

This disposable rehearsal used protocol commit `0be136bd43b7ae94c776857e0cfa0bee3752c9f7`
and deployment tooling `da14dd26a7ae7aa4749ff4c379a44dcd480cec53`. It recorded
34 facets / 283 selectors, a connected Genesis replica, and two registered
Morpho markets. Its separate addresses were:

The Morpho markets were staked STATICS/USDstx and TPA1/USDstx, both configured
with 77% LLTV and testnet oracle fixtures. The performance-fee router was
unset. See the [rehearsal manifest](https://github.com/EqualFiLabs/statics/blob/ca509b76e35103d0bccccb86876caa94711f37e8/deployments/robinhood-testnet-46630-rehearsal-20260903T033729Z.json)
for the complete addresses and validation record. This page makes no claim
about either snapshot's present live health.

## Not production

This deployment is an integration beta. Production must replace the mock USDG
and oracle fixtures, choose a reviewed staking-token policy rather than the
uncapped owner-mintable test token, verify the chain-selected governance delay,
select production roles and parameters, and qualify a single exact release
revision. See [Security model](/docs/reference/security-model).
