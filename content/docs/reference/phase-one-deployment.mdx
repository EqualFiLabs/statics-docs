The Statics Phase 1 protocol was deployed on Robinhood Chain mainnet (chain ID `4663`). The [machine-readable deployment snapshot](/deployments/robinhood-mainnet-phase-one-4663.json) records the addresses, runtime hashes, four created pools, launch settings, and transaction evidence verified at block **86,352,823** on **2026-10-12 03:19 UTC**. It was built from [Statics source commit `03c6d23`](https://github.com/EqualFiLabs/statics/tree/03c6d23cd8207c6f69b6b9a53b56f103c30ee52c).

:::warning Snapshot, not a live quote
At verification, all four pools had **zero active liquidity**, the protocol gauge was **not activated**, no pool had activated managed POL, and the POL operator was unset. Pool existence alone does not establish tradeable depth or funded rewards. Check current onchain state before transacting.
:::

## Verified launch settings and remaining checks

At the verification block, public pool creation cost **0.01 ETH**, PositionNFT creation cost **0.001 ETH**, optional managed-POL activation cost **0.025 ETH**, and the revenue settlement tip was **100 BPS** of Treasury's settled share. The launch sequence enabled the public creation fee before transferring ownership to the Safe. The [pool guide](/docs/liquidity/protocol-pools) explains how to obtain a fresh `quotePool(params)` before creation.

The deployment verifier matched core and periphery runtime hashes, launch configuration, and pool creation events. **Explorer source verification was not performed**, and this docs release does not bundle a compiled Phase 1 ABI or certify an SDK build against the deployment. Builders should compile the matching interfaces from source commit `03c6d23`, check installed selectors and current dependencies, and confirm the relevant onchain values. The [integration guide](/docs/reference/integration) covers those checks. Statics Genesis has a [separate mainnet manifest](https://github.com/EqualFiLabs/statics/blob/03c6d23cd8207c6f69b6b9a53b56f103c30ee52c/deployments/robinhood-mainnet-genesis.json).
