This guide targets the [previous public integration-beta release](/docs/reference/robinhood-testnet-deployment#previous-public-release),
with its ownerless faucet and genesis basket. Its addresses and SDK pin are not
those of the newer September rehearsal. Verify the target's current state and
faucet inventory before sending transactions; this guide is not a live-health
attestation. Basket **creation** is recorded as protocol-only on this deployment
— see [Rollout](/docs/rollout).

## What you can do in this guide

1. Connect to testnet and claim faucet fixtures.
2. Open a PositionNFT and stake `STATICS`.
3. Mint pegged Statics Dollar (`USDstx`).
4. Mint, redeem, or trade the genesis basket **TPA1**.

## Faucet

| Field | Value |
| --- | --- |
| Address | `0xDc74E592efbe3CE5A86785E89E50b53Fe0F8F04E` |
| Cooldown | One day per wallet |
| Inventory | Mock USDG, STATICS, TSLA, PLTR, AMD |

The faucet is ownerless with a fixed inventory. Use the SDK helper
`buildTestnetFaucetClaimCall()` to build the claim calldata.

:::note Testnet fixtures
The faucet, mock USDG, mock oracles, and owner-mintable STATICS token are
testnet fixtures. They are deliberately not production defaults.
:::

## Fund a wallet

1. Connect to Robinhood Chain Testnet (chain ID `46630`) and fund the wallet
   with native testnet ETH for gas. The listed Statics faucets dispense tokens,
   not native gas; the claim transaction and PositionNFT creation fee both need
   ETH.
2. Claim testnet assets from the faucet.
3. Approve `StaticsDiamond` (`0x2340741Ec94dF12678312f564eBc2c776d8FaA6a`) for
   the asset you want to use.

Full addresses live on the [deployment snapshot](/docs/reference/robinhood-testnet-deployment).

## Open a position and stake STATICS

```solidity
IERC20(staticsToken).approve(staticsDiamond, 100e18);

uint256 positionId = globalRewards.createAndStake{value: creationFee}(
    100e18,
    msg.sender,
    rewardAssets
);
```

`creationFee` is `0.001 ETH` on testnet. See
[Integration](/docs/reference/integration) for the full set of common flows.

## Try the pegged Dollar

The active pegged profile is Mock USDG profile `2` (5-BPS mint fee, 7-BPS
redemption fee, `1,000,000 USDstx` debt ceiling). Approve the Diamond for Mock
USDG and call `mintPegged` to mint `USDstx`, or use the permit variant
`mintPeggedWithPermit`.

## Trade the genesis basket

TPA1 is a live three-constituent basket (`0.01` TSLA, `0.01` PLTR, `0.01` AMD per
BasketToken) with three canonical pools. Composition is a **testnet fixture
example** — launch compositions on later networks may differ and should be treated
as TBD until finalized.

Mint or redeem via the basket interface, or swap on the canonical pools through
the hook. You can also deposit TPA1 into a position and borrow self-backed
constituent credit within the basket LTV.
