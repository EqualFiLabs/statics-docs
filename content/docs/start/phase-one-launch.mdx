**Statics Genesis is already live on Robinhood mainnet.** Phase 1 is the first stage of the separate Statics protocol; it does not redeploy Genesis. The source implements four stages. Availability on a particular chain depends on a verified deployment and its enabled features, not on code being present in `master`.

:::warning Deployment status
This site does not yet publish a verified Robinhood mainnet Phase 1 protocol address or matching ABI. Wait for the release manifest before sending Phase 1 transactions.
:::

## In Phase 1

| Surface | What it enables |
| --- | --- |
| [Public pools](/docs/liquidity/protocol-pools) | Fee-paid public creation from launch; ERC-20/ERC-20 and native ETH/ERC-20 pairs, creator-selected static v4 LP fees, bilateral hook fees, and optional managed POL. |
| [Permissioned venues](/docs/liquidity/permissioned-pools) | Governance-created pools with creator-authorized terms, a separate hook, venue controllers, trusted router, and non-transferable approved LP positions. |
| [PositionNFTs](/docs/core/position-nft) and [global staking](/docs/rewards/global-rewards) | Transferable accounts, raw STATICS stake, reward-asset selection, eligibility, and claims. |
| [Range gauges](/docs/liquidity/canonical-lp-rewards) | PositionNFT-managed v4 liquidity, native LP fees, protocol STATICS incentives, four direct-funded reward slots, allocator rewards, and claims. |
| [Managed POL](/docs/liquidity/permanent-liquidity) | Claim-backed inventory and explicit custody-constrained position management outside the swap callback. |

Phase 1 also includes timelocked configuration, guardian stops, treasury accounting, creator revenue, reward restrictions, bounded market views, and atomic reward batches. See the [protocol's accepted launch plan](https://github.com/EqualFiLabs/statics/blob/master/docs/adr/staged-phase-one-launch.md) for the exact selector and audit boundary.

## Phase 1 launch fees

The Robinhood mainnet Phase 1 launch scripts require these initial settings. They are **source configuration, not a verified live quote**; read the matching deployment and current onchain values before transacting.

| Action or rate | Phase 1 mainnet launch setting |
| --- | ---: |
| Create a public pool | 0.01 ETH, paid exactly by every caller |
| Create a PositionNFT | 0.001 ETH |
| Activate managed POL for a public pool | 0.025 ETH, only if activated |
| Public hook fee default | 500 pips (5 BPS) on input and 500 pips (5 BPS) on output |
| Revenue settlement tip | 100 BPS (1%) of the settled Treasury share |

Anyone may create a public pool from launch by paying the exact creation fee. `quotePool(params)` returns that fee and any optional POL activation payment. The launch operators verify an initial public pool before governance ownership passes to the timelock. Permissioned pool creation stays owner-only, with exact creator authorization; the Safe can create an initial venue before the handoff, and later creation goes through the timelock.

## Before using a deployment

1. Obtain the network-specific deployment manifest and ABI for the exact release.
2. Verify the protocol address, available functions, connected pool contracts, and governance configuration against that manifest.
3. Read current onchain fees, pool state, and reward configuration immediately before preparing a transaction. Use `quotePool(params)` before public-pool creation.
4. Treat rewards, POL growth, and trading volume as outcomes of actual funding and activity. No keeper or market activity is automatic.
