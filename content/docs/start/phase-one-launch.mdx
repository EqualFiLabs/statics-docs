**Statics Genesis is already live on Robinhood mainnet.** The separate Statics Phase 1 protocol is now deployed there. Phase 1 does not redeploy Genesis. The source implements four stages; only the installed features and their current configuration are available on a particular chain.

:::warning Check market readiness
The [Phase 1 deployment snapshot](/docs/reference/phase-one-deployment) publishes the verified protocol address and four pool IDs. At verification, those pools had no active liquidity, gauges were not activated, and the Safe still owned the protocol. This site does not bundle a matching compiled ABI. Confirm current onchain state and installed selectors before submitting a transaction.
:::

## In Phase 1

| Surface | What it enables |
| --- | --- |
| [Public pools](/docs/liquidity/protocol-pools) | Fee-paid public creation from launch; ERC-20/ERC-20 and native ETH/ERC-20 pairs, creator-selected static v4 LP fees, bilateral hook fees, and optional managed POL. |
| [Permissioned venues](/docs/liquidity/permissioned-pools) | Governance-created pools with creator-authorized terms, a separate hook, venue controllers, trusted router, and non-transferable approved LP positions. |
| [PositionNFTs](/docs/core/position-nft) and [global staking](/docs/rewards/global-rewards) | Transferable accounts, raw STATICS stake, reward-asset selection, eligibility, and claims. |
| [Range gauges](/docs/liquidity/canonical-lp-rewards) | PositionNFT-managed v4 liquidity, native LP fees, protocol STATICS incentives, four direct-funded reward slots, allocator rewards, and claims. |
| [Managed POL](/docs/liquidity/permanent-liquidity) | Claim-backed inventory and explicit custody-constrained position management outside the swap callback. |

Phase 1 also includes a deployed timelock awaiting ownership handoff, guardian stops, treasury accounting, creator revenue, reward restrictions, bounded market views, and atomic reward batches. See the [protocol's accepted launch plan](https://github.com/EqualFiLabs/statics/blob/master/docs/adr/staged-phase-one-launch.md) for the exact selector and audit boundary.

## Phase 1 launch fees

The [deployment snapshot](/docs/reference/phase-one-deployment) verified these Robinhood mainnet values at block **86,352,823**. They can change through governance; read current onchain values before transacting.

| Action or rate | Phase 1 mainnet launch setting |
| --- | ---: |
| Create a public pool after fee activation | 0.01 ETH, paid exactly by each caller |
| Create a PositionNFT | 0.001 ETH |
| Activate managed POL for a public pool | 0.025 ETH, only if activated |
| Public hook fee default | 500 pips (5 BPS) on input and 500 pips (5 BPS) on output |
| Revenue settlement tip | 100 BPS (1%) of the settled Treasury share |

Anyone may create a public pool by paying the exact creation fee. `quotePool(params)` returns that fee and any optional POL activation payment. Four public pools were created before ownership passed to the Safe. Permissioned pool creation stays owner-only, with exact creator authorization. The planned handoff from the Safe to the timelock had not occurred at verification.

## Before using a deployment

1. Read the [network-specific Phase 1 deployment snapshot](/docs/reference/phase-one-deployment) and compile the matching ABI from the pinned source commit.
2. Verify the protocol address, installed functions, connected pool contracts, and governance configuration against that snapshot and current onchain state.
3. Read current onchain fees, pool state, and reward configuration immediately before preparing a transaction. Use `quotePool(params)` before public-pool creation.
4. Treat rewards, POL growth, and trading volume as outcomes of actual funding and activity. No keeper or market activity is automatic.

For builders, the [architecture guide](/docs/core/architecture) explains the protocol's upgrade mechanism. The [integration guide](/docs/reference/integration) distinguishes Phase 1 paths from later-phase examples. The [rollout page](/docs/rollout) tracks the separate Genesis and phased-protocol releases.
