Statics is permissionless by design and staged in deployment. Current `master`
has moved beyond the recorded Robinhood testnet bytecode, so source availability
and deployment availability must be tracked separately.

Use this page to separate four clocks:

| Clock | Meaning |
| --- | --- |
| **Source** | Present in current `statics` master and its fresh-deployment tests |
| **Deployed** | Present in the recorded Robinhood testnet bytecode |
| **Enabled** | Open to ordinary users under current onchain parameters |
| **Conditional** | Possible when real activity, pricing, and risk conditions allow — never guaranteed |

## What you can do now

On the integration beta, ordinary users can:

- claim faucet fixtures and [get started on testnet](/docs/start/testnet-onboarding);
- open a PositionNFT and stake `STATICS`;
- mint and redeem the live genesis basket (TPA1);
- swap on TPA1's canonical Uniswap v4 pools;
- deposit basket tokens, borrow self-backed constituent credit, repay, extend, and recover;
- mint pegged `USDstx` against the active Mock USDG profile;
- stake eligible protocol-pool LP positions where configured.

Ordinary users **cannot** create new baskets while the creation fee is zero.
They also cannot use the current-source permissionless general-pool or Operators
launch APIs against the recorded deployment.

## Who can create baskets

Onchain creation has two modes, switched by `creationFee()`:

| `creationFee()` | Who may create |
| --- | --- |
| **Zero** | Diamond owner only (controlled genesis). Public creation is closed. |
| **Positive** | Any caller that pays the exact native fee. |

There is **no onchain partner role or asset allowlist**. While creation is owner-only, the protocol may still deploy baskets for selected partners through the same genesis path as an operational choice — that is offchain coordination, not a separate contract mode.

See [Basket creation](/docs/baskets/creation).

## Expected basket focus

| Phase | Creation access | Basket focus |
| --- | --- | --- |
| **Initial launch / current beta** | Protocol only | Curated baskets. Testnet uses tokenized-stock fixtures (TPA1); exact launch compositions remain TBD until finalized. |
| **Partner operations** | Protocol deploys for approved partners | Selected partner tokens and configurations, still via owner-controlled creation while the fee is zero |
| **Open creation** | Anyone paying the creation fee | Compatible ERC-20 assets, subject to protocol requirements and token-behavior risk |

Statics is a generic fixed-bundle basket protocol (1–16 ERC-20s), not a stock-only product. Tokenized-stock baskets are the concrete early example.

## Path to open creation

Open (fee-gated) creation is a **parameter change** (`setCreationFee` under governance), not a separate product build. It depends on security review and release qualification, production staking-token and role configuration, economic parameters and monitoring, and market readiness.

No calendar date is committed in these docs. Creation is open only once governance has actually raised the creation fee above zero — that onchain value is the authoritative signal.

## Source and deployment matrix

This matrix prevents current source from being mistaken for the recorded live
deployment:

| Surface | Source | Recorded testnet |
| --- | --- | --- |
| Permissionless basket creation | Implemented | **Disabled** while `creationFee = 0` |
| Governed protocol pools | Superseded by normalized basket/general registry | Deployed; governance-created only |
| Permissionless general pools | Implemented with independent fee switch and creator authorization | Not deployed |
| Fixed 5% protocol-pool creator share | Implemented | Not deployed in the current-source form |
| STATICS Operators standalone launch | Implemented and verification-gated | Not deployed; production hash is zero |
| Redrawable Operator secured credit | Implemented | Not deployed |
| Flash arbitrage receiver | Implemented; no profit guarantee | Available for compatible live baskets |
| Permanent liquidity compounding | Permissionless; depth depends on activity | Available for registered live pools |
| Dollar volatile profiles / risk recovery | Implemented | Check which profiles are active |
| Production immutability | Later release ceremony | Not completed |

The source-only Operators launch fixes supply and custody at 1B STATICS, 800M
Doppler inventory, 100.1M native treasury vesting, 99.9M backing for the 555
treasury-vesting Operators, and 5,000 Vault-owned Operators. These are
deterministic source facts, not a live-deployment or market-valuation claim.

## Outcomes are conditional

Additional mint, redeem, and pool paths may increase activity when prices
diverge, and activity can generate swap and non-swap fees. Fee shares may
compound into permanent protocol-owned liquidity when inventory matches. Self-backed
basket credit and Statics Dollar minting are available only within configured
risk limits. None of these outcomes is guaranteed: volume, rewards, liquidity
growth, and peg maintenance all depend on real market activity.
